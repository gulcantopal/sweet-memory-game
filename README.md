# Sweet Memory 🎀

Sweet Memory is a pastel-themed 2D memory card game developed with Unity.  
The game is designed for mobile portrait screens and includes visual card matching, level progression, score tracking, sound effects, and bilingual UI support.

## 🎮 Features

- 2D memory card matching gameplay
- Pastel / kawaii themed user interface
- Visual card icons instead of text-based cards
- 10 progressive levels
- Time limit and move limit system
- Lives system
- Score tracking
- Hint system
- Sound effects and background music
- Turkish / English language support
- Mobile portrait layout

## 🧩 Gameplay

The player tries to find matching pairs by flipping cards.  
Each level increases the challenge with more cards, limited time, and move restrictions.  
The player has limited lives and hint rights during the game.
